# Q-MÉTIER Features Directory

This directory contains feature request markdown files that are automatically processed by the AI-Agent.

## How It Works

1. Create a new `.md` file in this directory describing your feature
2. The AI-Agent (or Kiro hook) automatically detects the new file
3. Code is generated, tested, built, and deployed automatically

## Feature Template

```markdown
# Feature Title

Brief description of what this feature does.

## Requirements
- Requirement 1
- Requirement 2

## API Endpoints (if applicable)
- POST /endpoint - Description

## UI Components (if applicable)
- ComponentName - Description

## Tests
- Test scenario 1
- Test scenario 2
```
