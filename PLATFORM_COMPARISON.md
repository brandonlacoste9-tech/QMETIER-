# Q-MÉTIER vs Q-EMPLOIS - Platform Comparison

**Two Quebec-first platforms, two different approaches**

---

## 🎯 CORE DIFFERENCE

### Q-MÉTIER (Trades & Services)
**Quote-based marketplace for professional services**

- Customer posts project → Professionals submit quotes → Customer chooses best quote
- Focus: Licensed trades and professional services
- Target: Homeowners, businesses needing quality work
- Professionals: Plumbers, electricians, contractors, etc.

### Q-EMPLOIS (Tasks & Gigs)
**Task-based marketplace for any job**

- Customer posts task → Taskers claim task → Work gets done
- Focus: Any task, any job, anyone can do it
- Target: Anyone needing quick help with anything
- Taskers: Students, retirees, freelancers, anyone

---

## 📊 SIDE-BY-SIDE COMPARISON

| Feature | Q-MÉTIER | Q-EMPLOIS |
|---------|----------|-----------|
| **Model** | Quote-based | Task-based |
| **Who Posts** | Customers post projects | Customers post tasks |
| **Who Responds** | Pros submit quotes | Taskers claim tasks |
| **Selection** | Customer picks best quote | First to claim gets it |
| **Credits** | Pros buy credits to submit quotes | Taskers buy credits to claim tasks |
| **Verification** | Tier 1 (free) + Tier 2 ($25) | Basic ID check |
| **License Check** | Yes (RBQ, CMEQ, CMMTQ) | No (not required) |
| **Service Types** | 50+ professional services | 100+ any tasks |
| **Target Users** | Licensed professionals | Anyone |
| **Typical Jobs** | Plumbing, electrical, renovation | Moving, cleaning, delivery |
| **Job Size** | $500-$10,000+ | $20-$500 |
| **Timeline** | Days to weeks | Hours to days |
| **Quality Focus** | High (licensed pros) | Medium (anyone can do it) |

## 🎯 WHICH PLATFORM TO LAUNCH FIRST?

### Launch Q-EMPLOIS First

**Pros:**
- Lower barrier to entry (no licenses)
- Faster user acquisition
- Broader market (anyone can be a tasker)
- Simpler verification process
- Quicker to revenue

**Cons:**
- Lower average transaction value
- More competition (Kijiji, Facebook)
- Quality control challenges

### Launch Q-MÉTIER First

**Pros:**
- Higher transaction values
- Less competition (no TaskRabbit equivalent)
- Professional reputation
- License verification = trust

**Cons:**
- Slower user acquisition (need licensed pros)
- More complex verification
- Longer sales cycle

### Recommendation: Launch Both Simultaneously

**Why:**
- Shared infrastructure = minimal extra cost
- Cross-promotion opportunities
- Cover both markets
- Diversified revenue
- Test which gains traction faster

**Strategy:**
- Same beta offer (50 users, 60 free credits)
- Same timeline (4 weeks to 50 users)
- Same marketing channels (adapted)
- See which grows faster
- Double down on winner
